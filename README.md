# ספר המתכונים 📖

ספר מתכונים דיגיטלי אישי. זה אתר אינטרנט שאפשר גם להתקין על אייפון ואנדרואיד כמו אפליקציה, והוא עובד גם בלי אינטרנט.

## מה יש בו
- חיפוש לפי שם, מצרך או תגית, וסינון לפי קטגוריות
- מועדפים (נשמרים במכשיר)
- שינוי מספר המנות או הכפלת כמות, והכמויות מתעדכנות אוטומטית
- מעבר בין גרסאות של מתכון (למשל שוקולד או קינמון)
- סרטון הדגמה בתוך המתכון (YouTube או קובץ וידאו)
- סימון של מצרכים ושלבים תוך כדי בישול
- כפתור "מסך דולק" שמונע מהמסך להיכבות בזמן הבישול
- שיתוף והדפסה
- מצב כהה אוטומטי
- עבודה בלי חיבור לאינטרנט (PWA)

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `data/recipes.js` | **כל המתכונים**. כאן מוסיפים ועורכים |
| `images/` | תמונות של המתכונים |
| `index.html`, `css/`, `js/` | האפליקציה עצמה |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה כאפליקציה ועבודה בלי אינטרנט |

## הוספת מתכון
מוסיפים אובייקט חדש לרשימה ב־`data/recipes.js`. המבנה המלא מתואר בראש הקובץ.
אם יש תמונה, שמים אותה בתיקייה `images/` ומפנים אליה בשדה `image`.

אחרי שינוי בקבצי האפליקציה כדאי לעדכן את `VERSION` ב־`sw.js`, כדי שמכשירים שכבר התקינו יקבלו את הגרסה החדשה.

## פרסום ב־GitHub Pages (חינם)
1. ממזגים את הקוד לענף `main`.
2. נכנסים ב־GitHub ל־**Settings → Pages**.
3. תחת **Source** בוחרים **Deploy from a branch**, ואז `main` ותיקייה `/ (root)`.
4. אחרי דקה-שתיים האתר יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.

## התקנה בטלפון
- **אייפון (Safari):** פותחים את הכתובת, לוחצים על כפתור השיתוף ואז על "הוספה למסך הבית".
- **אנדרואיד (Chrome):** פותחים את הכתובת ולוחצים "התקנה" בהודעה שמופיעה, או בתפריט ⋮ בוחרים "התקנת אפליקציה".

## הרצה מקומית
```
python3 -m http.server 8000
```
ואז פותחים את http://localhost:8000
